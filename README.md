# CreatorHub

Modern Creator & KOL Intelligence Platform for hospitality, travel, and lifestyle brands.

## Features
- **Master Directory**: 467 verified Indonesian creators across 9 regions (DIY Yogyakarta, DKI Jakarta, Jawa Timur & Bali, Jawa Barat, etc.)
- **Campaign Kanban Pipeline**: 5-stage tracking (`Outreach` → `Negotiation` → `Deal Agreed` → `Content Review` → `Live & Paid`)
- **No-Code Smart Contracts**: Automated Indonesian legal agreement generator with currency spelling (`terbilang`) and DP/Pelunasan terms
- **Real-time Google Sheets Sync**: Connected directly to the consolidated master database
- **Sleek Pill & Neumorphic Design**: Built with Vite, React, and Tailwind CSS

## Tech Stack
- React 19
- Vite 8
- Tailwind CSS v4
- Lucide React & Canvas Confetti
